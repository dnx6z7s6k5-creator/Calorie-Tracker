🥗 Calorie Tracker Website

A simple, browser-based calorie tracking website built with HTML, CSS, and JavaScript.
It helps users log foods, track calories and macronutrients, and visualize daily intake — all without accounts or servers.

🌟 Features

🍎 Log foods with:

Calories

Protein

Carbohydrates

Fat

📊 Automatic totals for calories and macros

🥅 Optional daily calorie goal

🌙 Dark mode toggle

📈 Visual macro chart (Chart.js)

💾 Data saved in the browser using localStorage

📱 Mobile-friendly design

🔄 Automatically resets each day

🧠 How It Works

Users enter food details into the form

Data is stored locally in the browser

Totals update instantly

A chart displays macro distribution

No login, database, or internet connection required after loading

🛠️ Technologies Used

HTML – page structure

CSS – styling and dark mode

JavaScript – logic, storage, and calculations

Chart.js – data visualization
